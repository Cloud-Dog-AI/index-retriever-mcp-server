## Finding (owner: cloud_dog_db package maintainer — NOT index-retriever)
cloud_dog_db/config/models.py:115 to_sync_url() returns str(make_url(self.url)) which MASKS the password
as '***' (SQLAlchemy URL.__str__ default). The CLOUD_DOG_DB__URL config path therefore sends a masked
password and fails auth on a passworded DB. The parts path (line 133) is correct: render_as_string(hide_password=False).
Workaround here: disposable trust/empty-auth DBs (auth is not part of §25 #5; dialect coverage is).
Recommended canonical fix: to_sync_url should use make_url(self.url).render_as_string(hide_password=False).
